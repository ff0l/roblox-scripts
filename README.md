# roblox-scripts

Experimental Luau scripts for a few Roblox places. Not the main work on this account — that is [imgui-menu](https://github.com/ff0l/imgui-menu) and [roblox-dumper](https://github.com/ff0l/roblox-dumper).

Each folder is standalone. Execute that folder's `script.lua`.

## Projects

### Blade Ball

[bladeball](bladeball) · Place `13772394625`

Auto-parry timing, in-game menu, executor input helpers.

### Bad Business

[bad-business](bad-business)

Aimbot (smooth / FOV), ESP, chams, fly / speed / noclip. End unloads.

### RIVALS

[rivals](rivals)

Combat and visual modules, in-game menu, optional config persist.

### Chicken Farm

[chicken-farm](chicken-farm) · Place `137233438285284`

Automation helpers, remote / module discovery, in-game menu.

## Usage

1. Join the place.
2. Execute `script.lua` from that folder.
